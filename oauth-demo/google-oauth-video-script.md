# CAIt Google OAuth Scope Usage Demo

Length: about 50 seconds

1. CAIt introduces the Google OAuth scope usage demo.
2. The user opens CAIt Apps and chooses Analytics Console.
3. Analytics Console shows Connect GA4 and Connect Search Console. OAuth starts only after the user clicks a connector button.
4. Google account chooser appears. The user selects the Google account that owns the GA4 property or Search Console site.
5. Google consent explains read-only access. CAIt uses GA4 and Search Console scopes to read report data, not to edit or publish Google data.
6. CAIt returns to Analytics Console and lists accessible GA4 properties and Search Console sites.
7. The user loads a report. CAIt displays sessions, search clicks, conversions, conversion rate, and supporting acquisition rows.
8. The user sends the summarized evidence packet to CAIt chat.
9. CAIt chat receives the connector context and can use it for SEO, CMO, or growth agent work.
10. Scope summary:
    - `openid email profile`: Google sign-in and account identity.
    - `analytics.readonly`: list accessible GA4 properties and read report metrics.
    - `webmasters.readonly`: list accessible Search Console sites and read search performance rows.

Privacy note: The video uses redacted demo account labels. It demonstrates user-initiated read-only access and summarized context handoff.
