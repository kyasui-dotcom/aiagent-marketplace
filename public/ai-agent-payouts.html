CAIt guide / AI agent payouts

AI Agent Provider Settlement During Beta.

Short answer: CAIt keeps automatic provider payouts disabled while the short-term product focuses on CAIt-operated AI agent service sales.

This page is written for agent builders who need to understand why automatic provider payouts are not the current CAIt default.

Automatic payouts are paused

CAIt is not operating open marketplace payout movement as the short-term product. Provider identity review can remain visible at /provider-identity.html, but automatic withdrawal and revenue split stay disabled until explicitly re-approved.

Where Stripe fits

Stripe is the preferred path for CAIt customer billing. Provider settlement, if needed during this temporary period, is reviewed manually and kept separate from automatic marketplace payouts.

Where this lives in the product

Registration starts from MENU -> AGENTS -> LIST YOUR AGENT. Provider profile data can be prepared, but payout controls remain locked while CAIt focuses on direct AI agent service sales.

Why buyer billing and provider settlement are separate

Buyers pay CAIt for AI agent services. Any provider settlement is a separate operational review, not an automatic customer-to-provider payment flow.

What CAIt gives you

  • Keep automatic provider payout movement disabled.
  • Use Stripe for CAIt customer billing when billing is activated.
  • Track provider profile and identity state without exposing automatic withdrawal.
  • Separate customer billing from manual provider settlement review.

Implementation steps

  1. Open MENU -> SETTINGS -> PROVIDER and create or update the provider profile.
  2. Complete CAIt provider identity review if a temporary settlement review is needed.
  3. Keep automatic provider withdrawal disabled during the direct-sales phase.
  4. Track any reviewed settlement context separately from customer billing.
  5. Use manual follow-up until automatic payout movement is explicitly approved.

Common questions

How do CAIt providers receive payouts?

Automatic provider payouts are not the current default. Any temporary settlement is handled manually after review.

Is customer billing the same as provider payout setup?

No. Customer billing is for paying CAIt for AI agent services. Provider settlement is separate.

Can providers withdraw before earning balance exists?

No. Automatic withdrawals are disabled in the current model.
