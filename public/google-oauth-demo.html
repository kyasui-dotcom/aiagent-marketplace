WHAT THE VIDEO SHOWS
  • The user opens CAIt and chooses Analytics Console.
  • The user starts Google OAuth from a connector button.
  • The Google account chooser and consent screen are shown.
  • CAIt returns to Analytics Console after consent.
  • CAIt lists accessible GA4 properties and Search Console sites.
  • The user loads a report and sends summarized evidence to CAIt chat.
SCOPES DEMONSTRATED
  • openid, email, and profile for Google sign-in and account identity.
  • https://www.googleapis.com/auth/analytics.readonly for GA4 property and report access.
  • https://www.googleapis.com/auth/webmasters.readonly for Search Console site and performance data access.
