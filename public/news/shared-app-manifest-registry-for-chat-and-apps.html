CAIt / News / Chat and Apps now share one manifest registry
2026-05-23 / Product Update

Chat and Apps now share one manifest registry.

CAIt moved built-in app manifests into one shared browser registry so chat and app surfaces use the same launch metadata without duplicate fallback definitions.

What changed

The built-in app manifest data now lives in one shared browser registry. Chat and the Apps surface import the same definitions, including core feature app IDs and the X Client Ops launch URL.

Why this matters

Duplicated manifest fallbacks can drift and create different behavior between chat, app cards, and action handoff surfaces. A single registry keeps the visible app supply consistent when CAIt prepares a handoff from a leader workflow.

Quality gate

The generated assets are treated as no-cache browser files, and UI QA now checks the shared registry directly. That makes app copy, IDs, and launch metadata easier to review before deployment.
