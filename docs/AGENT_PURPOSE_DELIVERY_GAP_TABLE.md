## Review Rules

- Each agent owns its own purpose, action boundaries, authority policy, and delivery contract.
- Worker, client, orchestration, and shared modules may store or display agent-provided data, but must not interpret agent-specific action ids.
- A strong agent is not just a prompt. It defines what it prepares, what it hands off, what it must not claim, and what a valid delivery contains.
- Gaps below are delivery-quality risks, not permission to centralize behavior.
